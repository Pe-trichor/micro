参数说明：

RMS ：root mean square 均方根，信号能量，即响度

peak ：峰值，最高振幅
## PDM 麦克风 RMS 诊断表

| 状态           | RMS 范围       | 判断                             |
|----------------|----------------|----------------------------------|
| 安静室内       | 100–500        | 正常噪声底                       |
| 敲桌面         | 1500–35000     | 明显响应                         |
| RMS ≈ 0        | -              | 麦克风失效或 PDM 链路坏           |
| RMS 恒高且不变 | -              | 可能短路、偏置错误或时钟异常     |
